# Site Responsivo SENAI: Estudo Com Café

> Repositório didático: site responsivo criado em sala de aula no SENAI para praticar HTML e CSS.

## Sobre o projeto

Site **Estudo Com Café**, com dicas para organizar a rotina de estudos. O foco do exercício é fazer o mesmo site se adaptar a telas de celular e de computador.

## Contexto acadêmico

Exercício aplicado em sala de aula no **SENAI-RJ**.

## Páginas

- `index.html`: página inicial, com dicas de preparação e organização do local de estudos.
- `video.html`: vídeos selecionados, incorporados do YouTube.
- `local.html`: página de localização com mapa incorporado e informações sobre cursos profissionalizantes.

## Conceitos trabalhados em aula

- Layout **responsivo** com *media queries*
- Folhas de estilo separadas para celular (`css/celular.css`) e desktop (`css/desktop.css`)
- Abordagem *mobile first*
- Incorporação de vídeos e mapas com `iframe`

## Tecnologias

- **HTML5**
- **CSS3** (media queries)

## Como executar

Clone o repositório e abra o arquivo `index.html` no navegador. Para testar a responsividade, redimensione a janela ou use o modo de dispositivo das ferramentas do desenvolvedor (F12).

```bash
git clone https://github.com/fabcurvello/siteresponsivosenai.git
```
